# Nathan Peek — Portfolio V2

A from-scratch React portfolio focused on strong typography, restrained motion,
and reliable cross-browser behavior.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The production site is generated in `dist/`. The included GitHub Actions
workflow deploys that folder to GitHub Pages whenever `main` is pushed.

In the repository settings, set **Pages → Build and deployment → Source** to
**GitHub Actions**.
